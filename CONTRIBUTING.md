# Contributing

Please read the agent guide before contributing to lessons or skills:

- Primary contributor guide: [AGENT_GUIDE.md](AGENT_GUIDE.md)

Quick developer commands

```bash
# Install dependencies
npm install

# Run the dev web app
npm run dev:web

# Run tests across the repo
npm test --workspaces --if-present

# Type checks
npm run check
```

If you're editing skills or agent docs under `.mosaic/skills/`, follow the formatting and frontmatter patterns in existing files. For questions about conventions, see `AGENT_GUIDE.md`.
